STA PRESENTER · 5:15–6:20. Walk from left to right. For an action starting at t, the input is the preceding five seconds ending one second before the action. The gap is forbidden. Sampling and tests enforce the strict cutoff—otherwise we would leak future information. Advance to show the rule. Some actions occur near the start of a recording, so not all five segments exist. We retain a validity mask rather than treating absent segments as real observations. STA PRESENTER · 6:20–7:25. The frozen pretrained R3D-18 encoder converts each valid one-second segment, sampled at 16 frames, into 512 features. Cache these features so both video models can use the same input. M0 ignores video. M1 averages valid segments and predicts verb and noun. M2 processes the valid sequence through a masked GRU. Comparing them asks whether visual evidence helps over the prior, and whether modelling order helps over pooling. Both video models are implemented and unit-tested, but those tests do not establish predictive quality. We have not yet demonstrated full trained-model results in the source notes.
